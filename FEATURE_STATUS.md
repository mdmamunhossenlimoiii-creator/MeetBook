## Release decision

**Not release-ready.** Owner-only gates remain:
- Verify the existing-account public profile/directory/consent projection migration against actual MeetBook accounts.
- Confirm Firebase project meetbook-65d30, Auth providers, authorized Pages domain, first Super Admin, and App Check decision. No production Rules publication has been verified.
- Ensure eligible user documents have banned explicitly set to Boolean false and any suspendedUntil value is absent, null, or expired; missing/malformed status now intentionally blocks image uploads.
- Deploy the Cloudflare image Worker and its SQLite Durable Object migration; configure Cloudinary API key/secret as Worker secrets; verify the actual Pages origin; set imageUploadEndpoint; configure outer Cloudflare abuse/rate controls; and test real profile/post/story/message uploads.
- Run isolated staging E2E for Runner authentication, one user-initiated reply, consent-gated public engagement, and real Gemini behavior. Mocked tests are not live evidence.
- Verify GitHub Pages/public URL behavior and investigate the historical Run #30 failure.

No credentials or secrets are requested or added here. No Firebase or production settings were changed, no live bot workflow was dispatched, and no merge, publish, or deployment was performed. MySocial remains separate and untouched.
