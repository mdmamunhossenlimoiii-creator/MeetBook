# MeetBook AI Bot Lab — Sandbox Preview

Open `index.html` in a browser (or serve this folder with any static HTTP server).

## Scope
- Standalone, mobile-friendly preview of bot identities, personality, memory consent, simulated controls, and activity logs.
- Uses sample data only and makes no network requests.
- No Firebase, Gemini, Firestore, live runner, real user accounts, or production writes.
- Every action is explicitly simulated and resets on reload.
- Global kill switch starts ON; no real bot is activated.

## Important
This is a UI/interaction prototype, not a live integration test and not proof that the underlying bot runner is connected. Real staging requires an owner-created isolated Firebase staging project, dedicated test accounts, protected secrets, and verified deployment configuration.

Permanent product exclusions remain: no live streaming, no video calling, and no Reels/short-video feed.
